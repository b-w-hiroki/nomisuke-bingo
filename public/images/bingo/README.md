# ビンゴ画像ディレクトリ

このディレクトリにビンゴアイテムのイラスト画像を配置してください。

## 画像ファイルの命名規則

`src/data/bingoItems.ts` で定義されている画像パスに合わせてファイル名を設定してください。

例:
- `beer.png` → `/images/bingo/beer.png`
- `sake.png` → `/images/bingo/sake.png`
- `wine.png` → `/images/bingo/wine.png`

## 推奨画像仕様

- **形式**: PNG, JPG, WebP
- **サイズ**: 推奨 400x400px 以上（正方形推奨）
- **背景**: 透明背景（PNG）または白背景
- **ファイルサイズ**: 100KB以下を推奨

## フォールバック画像

画像が読み込めない場合や存在しない場合は、`placeholder.png` が使用されます。
このファイルもこのディレクトリに配置してください。

## 画像の追加方法

1. 画像ファイルをこのディレクトリに配置
2. `src/data/bingoItems.ts` の `bingoItems` 配列に対応するエントリがあることを確認
3. 画像パスが正しく設定されていることを確認
